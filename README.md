# 🌌 Dual Realm Odyssey - رحلة العالمين

لعبة مغامرات تعاونية ضخمة للاعبين متصلين عبر الويب، حيث يتحكم كل لاعب بعالم مختلف ولكنهما مترابطان، ويجب عليهما التعاون لحل الألغاز والتغلب على التحديات.

## 🎮 فكرة اللعبة

**"عالم النور" و "عالم الظل"**
- اللاعب الأول يتحكم في "عالم النور" (ألوان دافئة، أشكال هندسية ناعمة)
- اللاعب الثاني يتحكم في "عالم الظل" (ألوان باردة، أشكال حادة وزاوية)
- العالمان متطابقان هندسياً لكنهما مختلفان في المحتوى والتحديات
- بعض الأبواب لا تفتح إلا عندما يقف اللاعبان في مواقع متناظرة في العالمين
- بعض الألغاز تتطلب من لاعب النور رؤية ما لا يراه لاعب الظل، والعكس

## 🎨 التصميم البصري

### الألوان:
- **عالم النور**: ذهبي (#FFD700)، برتقالي دافئ (#FF8C00)، أبيض لؤلؤي (#F8F8FF)
- **عالم الظل**: أزرق نيلي (#191970)، بنفسجي غامق (#4B0082)، فضي معدني (#C0C0C0)
- **عناصر التفاعل**: أخضر زمردي (#50C878) للإشارات المشتركة بين العالمين

### الأشكال:
- **عالم النور**: دوائر، منحنيات، أشكال عضوية ناعمة
- **عالم الظل**: مثلثات، مضلعات، خطوط حادة وزوايا قائمة
- **الشخصيات**: أشكال هندسية متحركة مع تأثيرات جسيمات (Particles) تعكس عالم كل لاعب

## 🗺️ حجم اللعبة والمراحل

### الهيكل العام:
- **5 فصول رئيسية**، كل فصل يحتوي على 4-6 مراحل
- **إجمالي المراحل**: 25-30 مرحلة
- **مدة اللعب المتوقعة**: 8-12 ساعة للاعبين المتعاونين

### أنواع المراحل:
1. **مراحل التعريف**: تعليم الآليات الأساسية (التزامن، الرؤية المتبادلة)
2. **مراحل الألغاز**: تتطلب تواصلاً لفظياً أو إشارات مرئية بين اللاعبين
3. **مراحل المطاردة**: الهروب من كيان مشترك يهدد العالمين معاً
4. **مراحل البناء**: بناء جسور أو منصات تتطلب تحركاً متزامناً
5. **مراحل الزعماء**: معارك تتطلب تنسيقاً عالياً بين هجمات النور والظل

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية**: HTML5 Canvas / WebGL (via Three.js أو Phaser.js)
- **الخادم**: Node.js مع Socket.io للاتصال في الوقت الفعلي
- **قاعدة البيانات**: Redis للحالة المؤقتة، PostgreSQL لحفظ التقدم
- **استضافة**: Vercel للواجهة، Railway أو Render للخادم

## 🚀 كيفية البدء

```bash
# استنساخ المستودع
git clone https://github.com/Adhamelenany/dual-realm-odyssey.git

# تثبيت الاعتماديات
cd dual-realm-odyssey
npm install

# تشغيل الخادم المحلي
npm run dev
```
